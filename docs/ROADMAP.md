# v0.5.0 之后的开发规划

v0.5.0 已将活动统计移到后端，通过版本化契约向仪表盘提供数据。下一阶段建议先验证既有用户升级后的体验，再扩展平台覆盖。以下是待执行的优先顺序，版本号和日期尚未排定。

| 顺序 | 要解决的问题 | 怎样验收 |
| --- | --- | --- |
| 1 · 升级与数据保留 | 从带有调用记录、Skill 备注和归档状态的旧安装升级到 v0.5.0。 | 使用隔离数据目录，升级前后逐项核对记录、备注和归档状态；重启后检查插件注册、活动页和管理页。记录旧版本、操作系统及结果。 |
| 2 · 活动统计与面板交互 | 验证日期筛选、每日排名和低频观察在异步取数时显示一致。 | 用同一组已知记录核对后端结果和面板数字。覆盖快速切换日期、无覆盖日期、读取失败后恢复，以及中英文切换。 |
| 3 · 桌面平台覆盖 | 在已有 Windows、macOS、Linux 自动化检查之外，逐步确认真实桌面宿主的可用范围。 | 按平台记录完整包安装、面板打开、重启与卸载结果。尚未实测的平台标为待验证。 |

下一次发布以完成的验收项和可复现的问题修复为依据。已执行的检查写入[验收记录](VALIDATION.md)。早期里程碑和当时的设计决策保存在 [v0.5.0 标签下的历史路线](https://github.com/zz11ss11zz/plugin-skill-manager/blob/v0.5.0/docs/ROADMAP.md)。
