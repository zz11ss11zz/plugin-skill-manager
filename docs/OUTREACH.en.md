# Outreach priorities and scope

The first priority is helping Codex users find the manager when they search a Skill directory by name or by task. Check the public listing, search results and installation separately. Record the query, date and outcome so that later checks can measure changes.

Use the GitHub release and bilingual installation guides as the starting point for users. Explain when to install the complete desktop plugin and when a companion Skill is appropriate. Keep the Glama listing current, investigate SkillsMP discovery, and revisit Smithery when its publishing route can be verified. Work on agentskill.sh remains paused.

Community outreach comes after the installation path is verified. Candidate activities include a Chinese walkthrough, an English developer demo and feedback from users who tried the complete package. Posts, submissions and direct outreach require authorization. Track successful installations, reproducible problems and actionable feedback.
