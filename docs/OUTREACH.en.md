## Product Hunt trial recruitment

Product Hunt is a secondary channel for reaching local Codex users who want to see which plugins and Skills they actually use. Skill directory discovery remains the first priority. Launch preparation is pending and no date is set.

- **Prepare the launch.** Install the [complete v0.5.0 package](https://github.com/zz11ss11zz/plugin-skill-manager/releases/tag/v0.5.0) on a clean Windows setup, run `node install.mjs check`, and open the panel in the Codex desktop sidebar. Record a 30–60 second English walkthrough of inventory, activity and reversible archiving. State the Node.js and Codex CLI requirements. Follow the [Product Hunt launch guide](https://www.producthunt.com/launch/preparing-for-launch).
- **Ask for voluntary feedback.** Link to a feedback form from the launch page. Ask which stage the respondent reached: download only, installation check failed, check passed but the panel did not open, or panel opened. For failures, request the operating system, step and short error message. Local logs are unnecessary.
- **Report results.** Use valid respondents as the denominator and report counts for passing the installation check and opening the panel separately. GitHub asset downloads are a separate measure and cannot establish Product Hunt attribution or installation success rates.
