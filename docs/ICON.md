# Icon assets

The current v0.4.1 plugin uses a transparent orange-gold double open-ended wrench, oriented lower-left to upper-right. Both `src/assets/orbit-color.png` (historical filename) and `src/assets/sidebar-wrench.png` contain the same ImageGen artwork selected on 2026-10-29.

`appIcon` supplies the dashboard/listing icon and packaged logo/composer fields; `sidebarIcon` supplies MCP discovery. Build output copies the same artwork into all three packaged icon locations.

`src/assets/marketplace-plug-wrench-color.png` retains the earlier blue/cyan plug and orange wrench design as an archived alternative. Earlier monochrome plug/wrench and charcoal sidebar designs have been superseded. No official marketplace submission or approval is implied.

The OpenAI mark used only for OpenAI built-in tool entries comes from https://openai.com/brand/ (https://cdn.openai.com/brand/openai-logos.zip). It is not the manager's own identity.
