## 四周推进规划表

### 2026-10-30 用户补充：优先让 find-skills 等检索入口找到本项目

用户明确的推广重点是：其他用户在 Skill 库或通过 find-skills 搜索时能够找到本项目。**下表 D1–D4 优先于原 A1–A10；先改善检索可发现性，再扩大社区曝光。** 社区发帖是辅助，不能替代搜索命中验收。

find-skills 是搜索与安装辅助 Skill，不是独立收录库。本机该 Skill 指向 skills.sh，并调用 `npx skills find <query>`。本轮读取已有 CLI 源码确认其搜索请求使用 skills.sh 的 `/api/search`；仓库 `add --list` 能列出文件，不证明目录的关键词搜索能命中。官方 FAQ 描述通过真实 CLI 安装统计进入榜单，但没有据此保证具体关键词排名或收录时效。
